# Внешний вид (UI)

Решение владельца (2026-10-05): **гибрид** двух референсов.

| Откуда | Что берём |
|---|---|
| [valheim-server-ui](https://github.com/jonasthim/valheim-server-ui) (MIT) | Тёмная тема по умолчанию, янтарный акцент. Сайдбар с секциями «Серверы / Инстансы / Администрирование» и полоской у активного пункта. Шапка страницы (надзаголовок, заголовок, подзаголовок, действия справа). Полоса плиток статистики. Вкладки сервера. Формы конфига с подсказками под полями и тумблерами. «Danger zone». Страница входа без карточки. |
| [OVH game-panel](https://github.com/ovh/game-panel) (Apache-2.0) | На главной — таблица серверов с заголовками капсом, мини-полосками CPU/RAM, кнопками питания в строке, «Настройки» / «Консоль». Пристыкованная снизу консоль с вкладками по серверам (фаза 5). |

Код и брендинг референсов не копируются (ODS у OVH — фирменная дизайн-система OVHcloud). Всё сделано на Mantine 9:

- `apps/web/src/theme.ts` — палитры `amber` (акцент) и `dark` (почти чёрные нейтральные), шрифты.
- `apps/web/src/app.css` — переменные фона, активный пункт меню, таблица в стиле OVH, плитки статистики.
- Компоненты: `Shell` (шапка + сайдбар, сворачивается; на мобильных — бургер), `Logo`, `PageHeader`, `StatTile`, `ThemeToggle`, `LanguageSwitch`, `AuthCard`.

Шрифты хранятся локально (без внешних CDN): Inter Variable и Source Code Pro (OFL, `@fontsource`). Иконки: lucide-react (ISC).

Правила:
- Тема переключается в шапке и сохраняется в браузере (Mantine color scheme manager).
- В меню только существующие страницы. Каждый пункт привязан к праву (`permission`), пункты без права скрыты. Сервер всё равно проверяет права сам.
- Нет данных — пишем «—» и причину, а не выдуманные цифры.
